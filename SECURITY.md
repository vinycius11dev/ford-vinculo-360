# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue or include exploit details in a public pull request.

GitHub private vulnerability reporting is not currently enabled or available for this private repository on its current plan. Contact the repository owner through a private channel already provided by the project maintainers and ask for a secure reporting path before sending sensitive details. The repository currently has no published security email address; this contact-path gap must be resolved by the owner before inviting external security testing.

Please include the affected component, impact, reproduction steps, and a suggested fix when possible. Do not include customer data, access tokens, passwords, or other secrets in the report.

## Supported versions

Only the current default branch is maintained. This project is a development/pilot application and is not approved for production use; see `docs/sprint-3-cybersecurity.md` for deployment prerequisites.
